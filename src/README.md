# Código reutilizable

Módulos previstos al extraerlos del notebook:

- `indice.py`: construcción y validación del índice compuesto (PCA, selección de componentes, varianza explicada).
- `panel.py`: estimaciones two-way FE, modelo estático y dinámico, submuestras.
- `diagnosticos.py`: sesgo de Nickell, prueba de Pesaran (CD), errores estándar de Driscoll-Kraay.
- `tablas.py`: exportación de tablas de resultados.
