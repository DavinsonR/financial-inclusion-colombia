Atlas de inclusión financiera

Colombia por departamento y municipio, 2018 a 2025

El mapa muestra la intensidad de la inclusión financiera de cada territorio en un año. Tres vistas de lo mismo: plano con las métricas alrededor, relieve para levantar un departamento y verlo aparte, y municipios para bajar a las 1.123 unidades. Al fijar un departamento en relieve se puede bajar a sus municipios desde el propio mapa. Elegir una región o un departamento acerca el encuadre a esa selección y deja los vecinos sangrando por el borde, para no perder de vista dónde está. El índice y sus dimensiones se explican en Metodología. Un territorio sin color no vale cero: es un territorio del que la Superintendencia no reporta datos ese año.

// El foco (la unidad bajo el ratón, o la fijada con un clic) NO es una celda de OJS a propósito. Si lo
// fuera, cada movimiento del ratón invalidaría todas las celdas que dependen de él y OJS reemplazaría el
// panel entero: unos noventa nodos por fotograma. Aquí es un bus de eventos con coalescencia por
// requestAnimationFrame, y los bloques se limitan a parchear texto y atributos de nodos que ya existen.
foco = {
  const oyentes = new Set();
  let fijado = null, encima = null;
  let ultimo = {id: null, fijado: false};
  let pendiente = false;
  const emitir = () => {
    pendiente = false;
    const id = encima ?? fijado;
    const estado = {id, fijado: id !== null && id === fijado};
    if (estado.id === ultimo.id && estado.fijado === ultimo.fijado) return;
    ultimo = estado;
    for (const f of oyentes) f(estado);
  };
  const pedir = () => { if (!pendiente) { pendiente = true; requestAnimationFrame(emitir); } };
  return {
    get: () => ultimo,
    idFijado: () => fijado,
    // El sobrevuelo no borra lo fijado: lo tapa mientras dura. Al salir del mapa vuelve lo fijado, que es
    // lo que hace que un clic sirva para dejar una unidad puesta y seguir leyendo sus cifras al lado.
    sobrevolar(id) { if (encima === id) return; encima = id; pedir(); },
    alternarFijado(id) { fijado = fijado === id ? null : id; encima = null; pedir(); },
    escuchar(f) { oyentes.add(f); f(ultimo); return () => oyentes.delete(f); }
  };
}

// Controles de HTML plano. Observable Inputs se carga desde un CDN y sin red los filtros se caen; además
// un filtro es interfaz corriente y debe vestir el mismo cromado que el gráfico. El envoltorio expone
// `value` y reemite `input`, que es lo que `viewof` necesita.
control = {
  const envolver = (etiqueta, interno) => {
    const caja = document.createElement("label");
    caja.style.cssText = "display:flex;flex-direction:column;gap:3px";
    const t = document.createElement("span");
    t.textContent = etiqueta;
    t.style.cssText = "font-size:11.5px;letter-spacing:.04em;text-transform:uppercase;color:var(--atl-ink-2)";
    caja.append(t, interno);
    Object.defineProperty(caja, "value", {get: () => interno.value, set: (v) => { interno.value = v; }});
    interno.addEventListener("input", () => caja.dispatchEvent(new CustomEvent("input")));
    return caja;
  };
  const estilo = "font:inherit;font-size:13px;padding:4px 6px;border:1px solid var(--atl-baseline);" +
                 "border-radius:4px;background:var(--atl-surface);color:var(--atl-ink)";
  return {
    seleccion(etiqueta, opciones, valor) {
      const sel = document.createElement("select");
      sel.style.cssText = estilo + ";min-width:200px";
      let grupoActual = null, destino = sel;
      for (const o of opciones) {
        if (o.grupo && o.grupo !== grupoActual) {
          grupoActual = o.grupo;
          destino = document.createElement("optgroup");
          destino.label = o.grupo;
          sel.append(destino);
        } else if (!o.grupo) { destino = sel; }
        const op = document.createElement("option");
        op.value = o.valor; op.textContent = o.texto;
        destino.append(op);
      }
      sel.value = valor ?? opciones[0].valor;
      return envolver(etiqueta, sel);
    },
    rango(etiqueta, [min, max], valor) {
      const caja = document.createElement("div");
      caja.style.cssText = "display:flex;gap:8px;align-items:center";
      const r = document.createElement("input");
      r.type = "range"; r.min = min; r.max = max; r.step = 1; r.value = valor ?? max;
      r.style.cssText = "width:160px;accent-color:var(--atl-div-pos-2)";
      const eco = document.createElement("output");
      eco.textContent = r.value;
      eco.style.cssText = "font-size:13px;font-variant-numeric:tabular-nums;color:var(--atl-ink);min-width:34px";
      r.addEventListener("input", () => { eco.textContent = r.value; caja.dispatchEvent(new CustomEvent("input")); });
      caja.append(r, eco);
      Object.defineProperty(caja, "value", {get: () => +r.value, set: (v) => { r.value = v; eco.textContent = v; }});
      return envolver(etiqueta, caja);
    },
    // El conmutador de vista es un grupo de botones, no un desplegable: son tres opciones y el usuario
    // debe verlas todas a la vez para saber que existen.
    vistas(etiqueta, opciones, valor) {
      const caja = document.createElement("div");
      caja.className = "atlas-vistas";
      caja.setAttribute("role", "group");
      caja.setAttribute("aria-label", etiqueta);
      let actual = valor ?? opciones[0].valor;
      const botones = opciones.map((o) => {
        const b = document.createElement("button");
        b.type = "button"; b.textContent = o.texto;
        b.setAttribute("aria-pressed", String(o.valor === actual));
        b.addEventListener("click", () => {
          actual = o.valor;
          marcar();
          caja.dispatchEvent(new CustomEvent("input"));
        });
        caja.append(b);
        return b;
      });
      const marcar = () => botones.forEach((x, i) => x.setAttribute("aria-pressed", String(opciones[i].valor === actual)));
      // El descenso a municipios escribe `value` desde fuera: los botones tienen que reflejarlo o la barra
      // acaba diciendo "Relieve 3D" mientras el mapa enseña municipios.
      Object.defineProperty(caja, "value", {get: () => actual, set: (v) => { actual = v; marcar(); }});
      return envolver(etiqueta, caja);
    }
  };
}

panelMetricas = {
  const caja = d3.create("div");

  // --- Cifra destacada. La mediana, no la media: el valor agregado municipal por habitante y el acceso
  // municipal tienen extremos reales de dos órdenes de magnitud, y una media los seguiría.

  cifra.text(mediana === null ? "—" : fmt(mediana));
  pieCifra.text(`${visibles.length} de ${datos.ids.length} unidades con dato · ${indicador.etiqueta.toLowerCase()}, ${anio}`);

  // --- Evolución: la mediana año a año, y encima la línea de la unidad enfocada. Comparten eje porque
  // son la misma magnitud; comparar una unidad contra una suma nacional exigiría dos escalas y eso no
  // se hace nunca.
  const bEvo = caja.append("div").attr("class", "atlas-bloque");
  bEvo.append("h3").text("Evolución");

  const medianas = datos.anios.map((_, k) => {
    const fila = datos.series[indicadorId][k];
    const vs = fila.map((v, i) => ({v, i})).filter(d => d.v !== null && enGrupo(d.i)).map(d => d.v);

mapa = {
  const {ancho, alto, margen} = vistaGeo;
  const svg = d3.create("svg")
    .attr("viewBox", [0, 0, ancho, alto])
    .attr("role", "img")
    .attr("aria-label", `${indicador.etiqueta} por ${nivel}, ${anio}. Vista ${vista}.`);

  // --- Encuadre. La proyección se calcula sobre TODOS los rasgos, no sobre los filtrados: si cambiara
  // con el filtro, el mapa saltaría de tamaño cada vez que se elige una región y sería imposible comparar.
  // El giro y el aplastado de las vistas en volumen son una sola matriz sobre el grupo, no 1.121 geometrías
  // recalculadas en JavaScript.
  const rasgos = proyeccion.rasgos, trazo = proyeccion.trazo;
  const marco = svg.append("g").attr("transform", `translate(0,${margen})`);
  const capa = marco.append("g").attr("transform", vistaGeo.matriz);

  const colorDe = (i) => {
    if (i === undefined || valores[i] === null) return tok("--atl-sin-dato");
    return enGrupo(i) ? escala(valores[i]) : tok("--atl-sin-dato");
  };
  const posicion = new Map(datos.ids.map((id, i) => [id, i]));
  const grosor = (px) => px / vistaGeo.escala;   // el trazo vive dentro del grupo escalado
  const ladoDe = (i) => { const c = d3.color(colorDe(i)); return c ? c.darker(0.85).formatHex() : tok("--atl-canto"); };

  // --- Relieve. Cada unidad se define una vez en <defs> y el bloque son copias <use> desplazadas: el canto
  // son N copias oscuras y encima va la cara con su color. Así el volumen cuesta N referencias por unidad y
  // no N caminos con toda la geometría repetida. El desplazamiento sale de `vistaGeo.subir`, que resuelve
  // cuánto hay que moverse DENTRO del grupo inclinado para que en pantalla el bloque suba recto.
  const CAPAS = vistaGeo.capas, PASO = vistaGeo.paso;
  const arriba = vistaGeo.subir(1);                 // un punto de pantalla hacia arriba, en el grupo inclinado
  const altoBloque = (CAPAS + 1) * PASO;
  if (CAPAS) {
    const defs = svg.append("defs");
    rasgos.forEach((f, k) => defs.append("path").attr("id", `pz-${k}`).attr("d", trazo(f)));
  }

  // --- El archipiélago, fuera de escala. San Andrés está a 700 km del continente y mide 26 km²: dentro del
  // encuadre obliga a encoger Colombia una quinta parte para dibujar un punto, y en un inserto proporcional
  // el punto sigue siendo un punto, porque lo que ocupa el recuadro es el mar entre las dos islas. Así que
  // no se dibuja su forma: se dibuja una ficha con su color, rotulada, y se dice que está fuera de escala.
  // Es el trato habitual con los territorios diminutos, y deja la unidad viva: se pasa el ratón y se fija
  // igual que cualquier departamento.
  const insulares = rasgos.filter(f => ES_INSULAR(f.properties.id));
  const fichaAlto = 18, fichaLado = 13;
  const cajaInsular = {x: 10, y: vistaGeo.alto - margen - (insulares.length * fichaAlto + 8)};
  const grupoInsular = insulares.length ? marco.append("g") : null;
  if (grupoInsular) {
    grupoInsular.append("text").attr("x", cajaInsular.x).attr("y", cajaInsular.y - 5)
      .attr("font-size", 9.5).attr("fill", tok("--atl-muted")).text("Archipiélago · fuera de escala");
  }

  // Cada pieza guarda su centro YA en pantalla: las fichas del archipiélago tienen su propio sitio y sin
  // esto la tarjeta de San Andrés apuntaría a un punto del Caribe continental.
  const posInsular = new Map(insulares.map((f, k) => [f.properties.id, k]));
  const piezas = rasgos.map((f, k) => {
    const kInsular = posInsular.get(f.properties.id);
    const dentro = kInsular !== undefined;
    return {
      f, k, kInsular, dentro, id: f.properties.id,
      centro: dentro
        ? [cajaInsular.x + fichaLado / 2, cajaInsular.y + kInsular * fichaAlto + fichaLado / 2]
        : vistaGeo.aPantalla(trazo.centroid(f))
    };
  });
  const rasgoDe = new Map(piezas.map(o => [o.id, o]));

  const opacidadDe = (id) => {
    const i = posicion.get(id);
    return (grupo === "Todas" || (i !== undefined && enGrupo(i))) ? 1 : 0.32;
  };

  // Orden de pintado: del fondo al frente EN PANTALLA, que con el giro ya no es de norte a sur. Al levantar
  // una unidad, la que está delante debe taparla, así que se pinta después.
  const unidades = capa.selectAll("g.unidad")
    .data(piezas.filter(o => !o.dentro).sort((a, b) => a.centro[1] - b.centro[1])).join("g")
    .attr("class", "unidad").attr("data-id", d => d.id)
    .attr("opacity", d => opacidadDe(d.id));

  if (CAPAS) {
    unidades.each(function (d) {
      const g = d3.select(this);
      // El canto lleva el color de la cara oscurecido, no un negro translúcido: veintiséis copias de un
      // negro al 34 % se suman hasta el negro puro y el bloque se lee como un agujero.
      const lado = ladoDe(posicion.get(d.id));
      for (let c = CAPAS; c >= 1; c--) {
        g.append("use").attr("href", `#pz-${d.k}`).attr("class", "canto")
          .attr("x", c * PASO * arriba[0]).attr("y", c * PASO * arriba[1]).attr("fill", lado);
      }
    });
  }

  unidades.append(CAPAS ? "use" : "path")
    .attr("class", "cara")
    .attr(CAPAS ? "href" : "d", d => CAPAS ? `#pz-${d.k}` : trazo(d.f))
    .attr("x", CAPAS ? (CAPAS + 1) * PASO * arriba[0] : null)
    .attr("y", CAPAS ? (CAPAS + 1) * PASO * arriba[1] : null)
    .attr("fill", d => colorDe(posicion.get(d.id)))
    .attr("stroke", tok("--atl-surface"))

LIENZO = ({ancho: 660, marco: 700, margen: 54, pad: 14})
// El archipiélago (DIVIPOLA 88) se dibuja aparte y tampoco cuenta para el encuadre: si contara, el marco
// tendría que abarcar 700 km de mar y Colombia se dibujaría una quinta parte más pequeña.
ES_INSULAR = (id) => String(id).slice(0, 2) === "88"
// Capas y paso del bloque, en unidades del lienzo. El canto son copias apiladas de la misma silueta, así
// que el paso tiene que quedar por debajo del punto o el borde sale peinado; la profundidad se consigue con
// más capas, no con pasos más largos.
RELIEVE = ({plano: {capas: 0, paso: 0}, relieve: {capas: 26, paso: 1.2}, municipios: {capas: 4, paso: 1.6}})

// La geometría se decodifica y se proyecta UNA vez por nivel. Cambiar de año, de indicador o de vista solo
// cambia colores y una matriz; volver a decodificar el TopoJSON de 1.121 municipios en cada cambio sería el
// gasto más caro de la página y no haría falta para nada.
proyeccion = {
  const objeto = Object.values(geo.objects)[0];
  const rasgos = topojson.feature(geo, objeto).features;
  const coleccion = {type: "FeatureCollection", features: rasgos};
  const continente = {type: "FeatureCollection", features: rasgos.filter(f => !ES_INSULAR(f.properties.id))};
  const proy = d3.geoMercator().fitSize([LIENZO.ancho, LIENZO.marco - LIENZO.margen], coleccion);
  const trazo = d3.geoPath(proy);
  return {rasgos, trazo, proy: (lonlat) => proy(lonlat), limites: trazo.bounds(continente)};
}

// La geometría de la vista: UNA matriz afín que gira, aplasta y encaja el país en el lienzo. Girar sobre un
// encuadre ya ajustado saca el mapa del marco —Colombia girada 28° mide unos 780 px de ancho sobre un lienzo
// de 660—, así que la escala de ajuste se calcula sobre las esquinas ya giradas, no sobre las originales.
// La misma matriz sirve para el mapa y para las etiquetas, que viven fuera del grupo inclinado.
vistaGeo = {
  const {ancho, marco, margen, pad} = LIENZO;
  const rel = RELIEVE[vista];
  const t = (vista === "municipios" ? -28 : vista === "relieve" ? -17 : 0) * Math.PI / 180;
  const ky = vista === "municipios" ? 0.66 : vista === "relieve" ? 0.74 : 1;
  // SVG: x' = a·x + c·y + e ; y' = b·x + d·y + f. Esto es aplastar(ky) ∘ girar(t).
  const [a, b, c, d] = [Math.cos(t), ky * Math.sin(t), -Math.sin(t), ky * Math.cos(t)];
  // El encuadre sigue al filtro. Con "Todas" es el país; al elegir una región o un departamento el mapa se
  // acerca a él y los vecinos siguen dibujados, sangrando por el borde: el recorte del lienzo los corta
  // solo. Sin esto, bajar a los 118 municipios de Antioquia dejaba una mancha del tamaño de una uña.
  const enFoco = proyeccion.rasgos.filter(f => {
    if (ES_INSULAR(f.properties.id)) return false;
    if (grupo === "Todas") return true;
    const i = posDe.get(f.properties.id);
    return i !== undefined && enGrupo(i);
  });
  const [[x0, y0], [x1, y1]] = enFoco.length
    ? proyeccion.trazo.bounds({type: "FeatureCollection", features: enFoco})
    : proyeccion.limites;
  const esquinas = [[x0, y0], [x1, y0], [x1, y1], [x0, y1]].map(([x, y]) => [a * x + c * y, b * x + d * y]);
  const X = d3.extent(esquinas, q => q[0]), Y = d3.extent(esquinas, q => q[1]);
  // Alto reservado arriba: el bloque más la altura extra de la unidad levantada, o el norte se sale.
  const alzada = (rel.capas + 4) * rel.paso;
  const s = Math.min((ancho - 2 * pad) / (X[1] - X[0]), (marco - margen - alzada - pad) / (Y[1] - Y[0]));
  const contenido = s * (Y[1] - Y[0]);
  // El lienzo se recorta al contenido por los dos lados. Colombia es más alta que ancha, así que con un
  // marco cuadrado un tercio del ancho se iba en margen y el mapa salía pequeño sin motivo. El mínimo de
  // 430 es lo que necesita la leyenda para caber en una línea.
  const anchoUtil = Math.max(430, s * (X[1] - X[0]) + 2 * pad);
  const [A, B, C, D] = [a * s, b * s, c * s, d * s];
  const E = anchoUtil / 2 - (s * (X[0] + X[1])) / 2;
  const F = alzada - s * Y[0];
  const det = A * D - B * C;
  return {
    margen, escala: s, paso: rel.paso, capas: rel.capas, lineal: [A, B, C, D], ancho: anchoUtil,
    // El lienzo se recorta al contenido: girado, el país es más ancho que alto y un marco fijo dejaría
    // una franja muerta arriba y otra abajo que encogen el mapa sin dar nada a cambio.
    alto: margen + alzada + contenido + pad,
    matriz: `matrix(${[A, B, C, D, E, F].map(v => v.toFixed(4)).join(",")})`,
    aPantalla: (q) => [A * q[0] + C * q[1] + E, B * q[0] + D * q[1] + F],
    // Un desplazamiento que en pantalla sale recto hacia arriba. Dentro del grupo inclinado "arriba" ya no
    // es (0,−1): hay que resolver M·v = (0,−px) o el bloque se levantaría torcido, siguiendo el giro.
    subir: (px) => [(C * px) / det, (-A * px) / det]
  };
}

  }
  const [lo, hi] = d3.extent(visibles);
  const r = rampas.secuencial();
  return d3.scaleLinear().domain(r.map((_, i) => lo + ((hi - lo) * i) / (r.length - 1)))
    .range(r).clamp(true).interpolate(d3.interpolateLab);
}
formato = indicador.decimales >= 3 ? d3.format("+.2f")
  : indicador.decimales === 0 ? d3.format(",.0f") : d3.format(",.2f")

// Leyenda continua, siempre presente, con el cero marcado cuando la escala es divergente y una muestra
// de "sin dato" para que la ausencia no se confunda con el extremo bajo.
leyenda = (g, ancho) => {
  const w = Math.min(300, ancho - 130), h = 9, x = 0, y = 22;
  const id = "grad-" + ancho + "-" + indicador.id;
  const dom = escala.domain ? escala.domain() : [0, 1];
  const [lo, hi] = [dom[0], dom[dom.length - 1]];
  const grad = g.append("defs").append("linearGradient").attr("id", id);
  d3.range(0, 1.001, 0.05).forEach(t => grad.append("stop")
    .attr("offset", `${t * 100}%`).attr("stop-color", escala(lo + t * (hi - lo))));
  g.append("text").attr("x", x).attr("y", y - 8).attr("fill", tok("--atl-ink-2"))
    .attr("font-size", 12.5).attr("font-weight", 600).text(`${indicador.etiqueta} · ${anio}`);
  g.append("rect").attr("x", x).attr("y", y).attr("width", w).attr("height", h)
    .attr("rx", 2).attr("fill", `url(#${id})`).attr("stroke", tok("--atl-ring"));
  const ejeX = d3.scaleLinear().domain([lo, hi]).range([x, x + w]);
  const marcas = indicador.escala === "divergente" ? [lo, 0, hi] : [lo, (lo + hi) / 2, hi];
  g.selectAll("text.marca").data(marcas).join("text").attr("class", "marca")
    .attr("x", d => ejeX(d)).attr("y", y + h + 12)
    .attr("text-anchor", (d, i) => i === 0 ? "start" : i === marcas.length - 1 ? "end" : "middle")
    .attr("fill", tok("--atl-muted")).attr("font-size", 10.5)
    .attr("font-variant-numeric", "tabular-nums").text(d => formato(d));
  g.append("g").attr("transform", `translate(${x + w + 18},${y})`).call(gg => {
    gg.append("rect").attr("width", h).attr("height", h).attr("rx", 2)
      .attr("fill", tok("--atl-sin-dato")).attr("stroke", tok("--atl-ring"));
    gg.append("text").attr("x", h + 6).attr("y", h - 1)
      .attr("fill", tok("--atl-muted")).attr("font-size", 10.5).text("sin dato");
  });
}

Cómo leerlo

El índice está estandarizado: cero es el promedio de los departamentos en la ventana de calibración (2018 y 2019) y las unidades son desviaciones estándar de esa ventana. Un valor de 2 significa dos desviaciones por encima de aquel promedio, no “el doble de inclusión”. Por eso la escala del índice es divergente, con el gris en el cero, y la de las variables es de un solo color: “corresponsales por 10.000 habitantes” no tiene un centro natural, solo más y menos.

Las tres vistas muestran los mismos datos. El relieve existe para separar una unidad de sus vecinas y poder mirarla: la altura de los bloques es constante y no codifica nada, porque una altura que dependiera del valor haría que las unidades de adelante taparan a las de atrás, y el dato de una unidad no debe depender de dónde cae en el mapa. El color sigue siendo el que lleva la magnitud, en las tres vistas.

Los límites del mapa

Los territorios sin color no son territorios sin inclusión financiera: son territorios de los que ninguna entidad vigilada reportó operaciones ese año. La diferencia importa y confundirlas es el error más fácil de cometer con estos datos.

El nivel municipal hereda además una limitación de la fuente: el valor agregado municipal del DANE es un reparto del PIB departamental, no una medición independiente, así que las razones que lo usan como denominador son aproximaciones.

El archipiélago de San Andrés no se dibuja con su forma: está a 700 km del continente y mide 26 km², de modo que dentro del encuadre encoge Colombia una quinta parte para pintar un punto, y en un inserto proporcional lo que ocupa el recuadro es el mar entre las dos islas. Va como ficha rotulada, fuera de escala, y responde igual que cualquier otro departamento. Dos municipios del panel (1.123 unidades) no tienen polígono en el Marco Geoestadístico 2024: aparecen en el ranking y en las cifras, pero no en el mapa.
